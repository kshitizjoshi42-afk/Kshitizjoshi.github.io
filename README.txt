# Kshitiz Raj Joshi — Academic Website

This is a self-contained, responsive academic portfolio website.

## Files
- index.html — website content
- styles.css — design and responsive layout
- script.js — mobile navigation and small interactions
- CV-Kshitiz-Raj-Joshi.pdf — add your own CV here before publishing

## Before publishing
1. Replace the portrait placeholder with your professional photo if desired.
2. Replace the LinkedIn / Google Scholar / ORCID / ResearchGate "#" links in index.html with your real URLs.
3. Add your CV PDF using the exact filename:
   CV-Kshitiz-Raj-Joshi.pdf
4. Review every claim and publication status for accuracy.
5. Update your email if you want to use another address.

## Free publishing options
### GitHub Pages
1. Create a GitHub account.
2. Create a new public repository, e.g. `kshitiz-academic-website`.
3. Upload all files in this folder.
4. In repository Settings → Pages, select the main branch and root folder.
5. GitHub will provide your public website URL.

### Netlify
1. Create a Netlify account.
2. Use "Add new site" → "Deploy manually".
3. Drag the website folder into the upload area.
4. Netlify will give you a public URL.

## Suggested final URL
